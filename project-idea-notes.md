# RabbitTracker - MVP highlights

## Problem definition

People with ADHD and other neurotic minds, tend to fall into rabbit hole when learning and searching for infomration.
This sometimes causes in completing task at hand, when additional details that are searched are not essential to
achieve objectives. For example I want to see whats a soft max formula, and instead of using the information I start
searching for properties and origin of the euler number. This is important to know - but causes the actual task
to be completed much later or not at all.

## Key feature set MVP
- allow user to learn about things they are interested in "instagram" like format
- accept from user keywords or topics encountered during their research 
- asynchronously s user's targeted feed with on topics they are interested and want to re-visit later
- allows "scrolling" through the feed in "instagram" like fashion
- each slide contains some small easy to process and visualised piece of information on the topic
- user gets informed once he sees all the feed that was prepared for him and can start over

## What's not included in MVP
- rating of the posts from feed
- sharing feed between users (feed prepared for one user is not exposed to another user even if the topic overlaps)
- providing posts if users have not defined any topic
- asking verification questions - quiz
- mobile and desktop app for now - just web interface
- no external integrations
- we don't do a  web search for information
- we don't accept user docs or links

## Success rate
- for 80% of topics/keywords we are able to create at least 5 posts to their feed
